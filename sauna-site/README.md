# Сауна 24/7 — saunalipetsk48.ru

Одностраничный сайт для хостинга.

## Загрузка на хостинг

Загрузите **содержимое** этой папки в корень сайта (public_html / www):

```
index.html
robots.txt
sitemap.xml
images/
  bedroom.webp
  hats.webp
  lounge.webp
  pool-wide.webp
  relax.webp
  sauna.webp
```

Не загружайте: `README.md`, папки `__pycache__`, служебные файлы хоста.

## Домен

- Сейчас: **http://saunalipetsk48.ru**
- После SSL: замените `http://` → `https://` в:
  - `index.html` (canonical, og:*, JSON-LD)
  - `robots.txt`
  - `sitemap.xml`
  и сделайте 301 с http на https.
